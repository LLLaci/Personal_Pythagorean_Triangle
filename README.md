# Personal Pythagorean Triangle

Stand alone streamlit app for convert a text to number. Then calculate a Pythagorean Triple from the converted number.  
For the calculation the app uses an slighty altered version of the [Euclid's formula](https://en.wikipedia.org/wiki/Pythagorean_triple#Generating_a_triple) and the find a unique psotion in the [Berggrens's tree of primitive Pythagorean triples](https://en.wikipedia.org/wiki/Tree_of_primitive_Pythagorean_triples).

[Streamlit app link](https://personalpythagoreantriangle.streamlit.app)
